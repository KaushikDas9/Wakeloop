# Product Overview

## What it is

A macOS menu bar app that holds the Mac awake **only while at least one AI coding agent session is working**, then allows sleep when the work is done.

## Status

Planning. Name chosen: **Wakeloop**. A web search found no existing Mac app with this name. Still to do: domain, GitHub org, npm, Homebrew and trademark checks (India and US).

## Goal (be honest)

A portfolio-grade, open-source project that proves you can ship a native Mac app with a privileged helper. Revenue is a possible bonus, not the plan (see [payments-india](../business/payments-india.md)).

## Why the plan changed

The first version assumed a free open-source core plus a paid Pro tier. Research on 2026-10-08 showed the space is crowded at every layer (see [competitive-landscape](../research/competitive-landscape.md)). A plain keep-awake app will not stand out, and paid pricing is hard against free alternatives that are already good.

## Constraints

- Do not copy any competitor's name, mascot, copy or branding.
- Native Swift app; no Mac App Store (sandbox blocks the helper).

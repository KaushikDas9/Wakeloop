# Competitive Landscape

Research date: 2026-10-08.

| Layer | Already covered by |
|---|---|
| Keep awake while an agent works | Agent Caffeine ($19), Hold My Lid ($10-15), Belay (free, notarized), Adrafinil (free, MIT), Vigil (two separate projects), StayUp, StayAwake, Lidless, Holdor, Puer, awake CLI, agentwatch |
| Auto-resume after a usage limit | Claude Code itself (v2.1.234+, session must stay open), unsnooze (multi-CLI, revives dead sessions), claude-auto-continue, claude-auto-retry |
| Phone alerts / remote | Vigil (reminder + free iPhone companion app), Agent Caffeine ("stay reachable"), Claude Code Remote Control, Codex remote |
| Usage meters, history | Vigil, Belay (statistics), agentwatch |

## Consequence

A plain keep-awake app will not stand out, and paid pricing is hard against free alternatives that are already good. See [differentiation](../product/differentiation.md) for the narrow angles worth testing.

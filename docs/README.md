# Wakeloop Docs

Wakeloop is a macOS menu bar app that keeps the Mac awake **only while an AI coding agent is actually working**, and lets it sleep when the work is done. Close the lid, walk away, the agent keeps going.

- **Status:** planning (last research pass: 2026-10-08)
- **Goal:** a portfolio-grade, open-source project that proves you can ship a native Mac app with a privileged helper. Revenue is a possible bonus, not the plan.
- **Do not copy** any competitor's name, mascot, copy or branding.

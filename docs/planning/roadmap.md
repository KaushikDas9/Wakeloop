# Roadmap

| Step | Scope |
|---|---|
| M0 - Research week | Use Adrafinil, Belay and Vigil on real agent runs; note gaps and bugs |
| M0 - Spike | Test lid-closed on your Mac (adapter and battery); test Claude Code hooks (`Stop`, `Notification`, `PermissionRequest`, `StopFailure`) end to end |
| M1 - MVP | Menu bar app, assertion while working, Claude Code + Codex detection, battery/heat guard, pause, notifications |
| M2 - Open source release | Repo, README, build script, license (decide MIT vs source-available **before** publishing), issue templates |
| M3 - Reliability | Process-tree and session-file detection, long silent commands, background jobs, "why is my Mac awake" panel |
| M4 - One differentiator | Pick the best hypothesis from [differentiation](../product/differentiation.md) after a demand check (post "I'm building this, would you use it?") |
| M5 - Signed build | Developer ID, notarization, Sparkle, landing page; sponsor or payment link |
| M6 - Launch | Soft launch to small groups, then Show HN / Reddit / X once stable |

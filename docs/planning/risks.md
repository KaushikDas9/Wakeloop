# Risks

| Risk | Mitigation |
|---|---|
| **Crowded market:** many free, maintained competitors | Pick a narrow differentiator or treat this as a portfolio project |
| **Agent formats change** | Keep detectors modular and tested; re-verify docs per release |
| **Privileged helper** is security-sensitive | One command only, watchdog, documented uninstall |
| **Heat and battery:** closed-bag misuse | Safety cutoffs on by default |
| **Platform dependence:** first-party features (Claude Code auto-continue, Remote Control) can absorb parts of any add-on | Treat add-ons as features, not a business; favor reliability |
